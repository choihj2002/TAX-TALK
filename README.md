# 세법말문제

공인회계사 1차 세법개론 기출(2017~2026, 1형) 말문제 200문항 풀이 사이트입니다. 빌드 과정이 없는 정적 사이트(HTML/CSS/JS)입니다.

## 기능
- 연도·세목·유형(오지선다/ㄱㄴㄷ) 필터, 순서대로/랜덤 출제
- 제출하면 정답/오답과 선지별 정·부 표시 (키보드 1~5, Enter, ←/→)
- 히스토리: 이번 세션(탭)에서 푼 문제의 정오 기록과 틀린 문제만 다시 풀기
- 선지 옆 ⊕ 버튼으로 헷갈리는 지문을 OX 장부에 담아 OX로 복습 (브라우저 localStorage에 저장)

## 파일
- `index.html`, `style.css`, `app.js`: 화면과 동작
- `questions.js`: 문제 데이터 (파일을 더블클릭해 열어도 동작하도록 JS로 넣음) (정/부는 확정답안 기준)
- `netlify.toml`: Netlify 배포 설정 (publish = 루트)

## 배포
Netlify에서 이 저장소를 연결하고, Build command는 비워 두고 Publish directory는 `.`로 둡니다.
