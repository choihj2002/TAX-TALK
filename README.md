# 세법말문제

공인회계사 1차 세법개론 기출(2017~2026, 1형) 말문제 200문항 풀이 사이트입니다. 빌드 과정이 없는 정적 사이트(HTML/CSS/JS)입니다.

## 기능
- 연도·세목·유형(오지선다/ㄱㄴㄷ) 필터, 순서대로/랜덤 출제
- 제출하면 정답/오답과 선지별 정·부 표시 (키보드 1~5, Enter, ←/→)
- 히스토리: 푼 문제의 정오 기록과 틀린 문제만 다시 풀기
- 저장한 세션: 한 번 푼 풀이에 이름을 붙여 저장(시간·맞춘 개수 표시), 이름 바꾸기, 삭제, 세션별 틀린 문제/안 푼 문제/전체 다시 풀기
- 모의고사: 한 해의 세목별 말문제 구성을 빌려 전 연도에서 출제, "제 N회 모의고사"로 자동 저장, 회차별 점수 추이 그래프와 세목별 정답률
- 선지 옆 ⊕ 버튼으로 헷갈리는 지문을 OX 장부에 담아 OX로 복습
- 질문게시판: 문제 질문 / 선지 질문 / 건의사항을 남기고(로그인 필요) 누구나 열람. 연도·문항·선지·종류 필터와 검색. 관리자(admins 테이블)는 게시판에서 바로 답변
- 로그인(Supabase Auth: 이메일+비밀번호, 메일 링크, Google, 카카오)
  - 로그인하면 히스토리와 OX 장부가 계정(Supabase 테이블)에 저장돼 다른 기기에서도 이어짐
  - 로그인 전 이 기기에 쌓인 기록은 로그인할 때 계정으로 옮겨짐
  - 로그아웃 상태에서는 예전처럼 히스토리는 탭(sessionStorage), OX 장부는 브라우저(localStorage)에 저장

## 파일
- `index.html`, `style.css`, `app.js`: 화면과 동작
- `questions.js`: 문제 데이터 (파일을 더블클릭해 열어도 동작하도록 JS로 넣음) (정/부는 확정답안 기준)
- `supabase-config.js`: Supabase 주소, publishable 키, 소셜 로그인 버튼 켜기/끄기
- (사이트 밖) `세법말문제_inquiries_setup.sql`: 질문게시판 테이블·관리자 설정
- (사이트 밖) `세법말문제_sessions_setup.sql`: 저장한 세션·모의고사 테이블(quiz_sessions)+RLS
- (사이트 밖) `세법말문제_supabase_setup.sql`: Supabase SQL Editor에 한 번 실행할 테이블+RLS 설정
- `privacy.html`: 개인정보처리방침 (Google·카카오 앱 등록에 쓰는 주소: /privacy.html)
- `netlify.toml`: Netlify 배포 설정 (publish = 루트)

## 배포
Netlify에서 이 저장소를 연결하고, Build command는 비워 두고 Publish directory는 `.`로 둡니다.
